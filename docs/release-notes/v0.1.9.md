# Pillar Brief v0.1.9

This release fixes the first feedback reporting issues found during local
testing.

## Fixed

- Feedback reports now explicitly send the `pillar-brief` product id in the
  submission payload.
- The feedback modal now scrolls when a pasted or uploaded screenshot expands
  the form, keeping the submit controls reachable.
- Screenshot previews are capped to a smaller height so the modal remains
  usable on shorter screens.

## Notes

- The shared feedback server was also updated to reject unknown explicit
  product ids instead of falling back to the PrismAI repo.

- Intel Mac: `Pillar.Brief_0.1.9_x64.dmg`
