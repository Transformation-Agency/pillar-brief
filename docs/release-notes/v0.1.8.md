# Pillar Brief v0.1.8

This release adds in-app feedback reporting and routes submissions to the shared
Transformation Agency feedback server.

## New

- Added a floating feedback button available across the app.
- Added a Help menu feedback action that opens the same reporting flow.
- Added bug, feature request, and general feedback categories.
- Added optional screenshot upload/paste support for feedback reports.

## Improved

- Feedback submissions include Pillar Brief-specific routing context so reports
  can land in the Pillar Brief GitHub repo.
- Release builds now pass `VITE_PILLAR_FEEDBACK_API_BASE` from GitHub Actions
  repository variables into the Vite build.

- Intel Mac: `Pillar.Brief_0.1.8_x64.dmg`
