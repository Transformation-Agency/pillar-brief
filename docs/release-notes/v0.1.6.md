# Pillar Brief v0.1.6

This release focuses on day-to-day control, exports, and release reliability.

## New

- Added brief deletion with a confirmation step so test runs and old briefs can
  be removed safely.
- Added concise, standard, detailed, and custom publishing controls in Brief
  Setup.
- Added Markdown export for saved briefs with a native desktop save dialog.
- Added styled PDF export for saved briefs with a native desktop save dialog.

## Improved

- Improved audio playback controls and sizing across compact and expanded
  desktop windows.
- Replaced the FFmpeg install dependency with bundled local audio conversion for
  desktop builds.
- Kept local speech-to-text on the bundled tiny English whisper.cpp model.
- Hardened release workflows with preflight checks, bundle sidecar validation,
  Windows whisper.cpp provisioning, and updater manifest validation.

- Intel Mac: `Pillar.Brief_0.1.6_x64.dmg`
