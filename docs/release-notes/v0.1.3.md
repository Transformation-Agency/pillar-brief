# Pillar Brief v0.1.3

This release adds Google Calendar agenda context, signed in-app desktop updates,
and a polish pass on desktop branding and onboarding.

## Highlights

- Added optional Google Calendar onboarding with read-only agenda access.
- Added a first-class "Today's Calendar" section in Brief Setup when Calendar is connected.
- Switched desktop Google Calendar OAuth to a secretless installed-app PKCE flow.
- Added signed Tauri updater support with Settings and Help menu controls.
- Added release automation for macOS updater artifacts, Windows updater artifacts, and `latest.json`.
- Refreshed Pillar Brief branding, app icon assets, README banner, and macOS tray icon.
- Added the actual Google Calendar connector icon in setup and settings.

## Fixes

- Calendar selections no longer re-check themselves while a user is editing them.
- Calendar OAuth opens outside the Tauri webview and returns to the app cleanly.
- Existing installs get the Calendar brief section moved to the top once without overwriting future manual ordering.
