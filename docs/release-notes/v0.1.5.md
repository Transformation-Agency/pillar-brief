# Pillar Brief v0.1.5

This release fixes the signed desktop updater flow introduced in v0.1.4.

## Fixes

- Restored desktop app version detection in Settings by using Tauri's built-in
  app version API.
- Decoupled version lookup from update checks so updater failures are reported
  accurately.
- Tightened Tauri permissions for the local desktop webview origin used by the
  bundled backend.
- Added explicit updater failure messages in Settings instead of the generic
  "Desktop only" fallback.

## Note

Users already on v0.1.4 may need to download and install v0.1.5 manually once
because v0.1.4's in-app update check can fail before it discovers this release.
Future updates should be detectable from inside the app.
