# Pillar Brief v0.1.4

This release adds a cleaner starter setup, crypto market snapshots, safer data
controls, and fixes for Google Calendar selections.

## Highlights

- Added a Recommended source library with review, select-all, and clear API-key
  or transcription prerequisites before sources run.
- Added CoinGecko crypto price sources with searchable asset selection.
- Added Settings controls to download a backup of local data and erase all data
  after explicit destructive confirmation.
- Added a desktop backup save flow that writes backups to Downloads and reveals
  the saved file.
- Improved source onboarding so optional setup-dependent sources can be skipped
  without blocking setup.

## Fixes

- Google Calendar selections no longer get replaced by stale per-source
  calendar IDs.
- Calendar-backed brief sections are inserted first in Brief Setup instead of
  being appended at the end.
- Desktop packaging now requires and resolves a Node 24+ sidecar for the
  backend.
