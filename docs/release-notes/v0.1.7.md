# Pillar Brief v0.1.7

This release focuses on stuck-run recovery and long podcast transcription.

## New

- Added stop-and-delete behavior for active brief runs from the Briefs tab.
- Added persistent background podcast transcription jobs.
- Added resumable chunk progress for large podcast episodes.
- Added source-table transcription status such as queued/running chunk progress.

## Improved

- Running workflow rows from interrupted app sessions are marked failed on restart
  instead of lingering as active zombie runs.
- Podcast transcription no longer blocks the entire source-fetch step for large
  episodes.
- Local Whisper transcription now uses a 20-minute timeout per chunk.
- Podcast episode notes with substantial text can be saved as transcript context
  without downloading and transcribing audio.
